Using the tools

User guides

Step-by-step guides for the people who use TYDAL and TYKERF, organized by role or task, with screenshots of each screen.

Updated 3 November 2026

These guides are for the people who use TYDAL and TYKERF: members who browse, upload and share resources, the administrators who look after an organization, and the people who build web pages with TYKERF. They are maintained alongside the code in each product’s repository, so they always match the latest release.

To install, configure or build on TYDAL, see the developer documentation. For TYKERF, see its developer guide.

TYDAL

TYDAL is where your organization’s resources live: the library, the upload wizard with AI suggestions, tags, workspaces and the Vaults that share content outside TYDAL. Start with the TYDAL user guide, or go straight to a chapter:

FullFrame, an example client

FullFrame is an independent application built on TYDAL that turns photographs into online exhibitions. Its user guides, for visitors, curators, invited authors, jurors and administrators, are in its own repository. For how an external client like it uses TYDAL, see FullFrame: an example client of TYDAL.
