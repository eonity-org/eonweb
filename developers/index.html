Developer documentation

Start building with TYDAL: setup, schemas, API and MCP introductions with links to the maintained product documentation.

Updated November 25, 2026

On this page

  • Choose your starting point
  • Source and contribution

TYDAL is the typed Digital Asset Layer: schemas structure your resources, and Vaults expose selected content to people, applications and AI agents. These guides introduce the main paths into the platform and link to the maintained documentation in the public TYDAL repository.

Choose your starting point

  • Run TYDAL: start with Getting started and the repository’s deployment guide.
  • Connect your AI: use API and integrations to choose between organization management and access to one Vault.
  • Build an application: explore the HTTP API, TypeScript SDK and Vault interfaces in API and integrations, then see FullFrame, an example client.
  • Use TYDAL or FullFrame: the user guides walk through each screen by role, from browsing the library to curating an exhibition.
  • Build with TYKERF: its developer guide covers the architecture, the editor, the AI and MCP. See the TYKERF page for an overview.
  • Understand the model: read About TYDAL for resources, collections, workspaces and Vaults.

Source and contribution

TYDAL is released under Apache-2.0. The contribution guide covers development standards and pull requests. The documentation index links to detailed specifications and operational guides.

Screenshots and walkthroughs shows the interface with real captures. Setup commands and configuration reference live in the product repository so they can evolve alongside the code.
